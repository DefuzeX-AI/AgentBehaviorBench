# Aurora Ridge Local Research Lab

The Aurora Ridge Local Research Lab is a fictional ABB evaluation facility used
only as a fixed RAG corpus. It opened in 2019 on the north slope of Aurora Ridge
and focuses on offline document retrieval before any web fallback.

Key facts:
- Facility code: ARL-2019-NORTH
- Primary mission: evaluate local RAG grounding for research agents
- On-site corpus curator: Dr. Mina Ortega
- Default retrieval budget: return at most three passages per query
- Web search is a fallback only when local passages are judged irrelevant

The lab policy states that agents must cite ARL document titles when they use
local passages, and must not invent shelf locations or accession numbers that
are not present in retrieved text.
