# Native read Local Smoke v1

This is a custom deployment-acceptance Case, not official KUMA or a GT candidate. It asks the unchanged Gateway-backed Agent to use its actual native read tool on its installed package manifest and report three verifiable fields. The source file is part of the original frozen repository. The Case requires a real read, not an answer inferred from existing system context.

The accepted evidence must contain the actual native read request/output, the original Agent response, complete model interception/SDK Trace, strict Local Judge result and host cleanup. Native tools, prompts, independent approval settings and Judge contracts are unchanged. A successful read does not certify shell execution, messaging, browsers, external MCP or filesystem preservation. One frozen Case and one Judge call are budgeted; no sampling until a desired verdict is returned.
