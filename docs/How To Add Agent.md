```bash
agentbench agent add https://github.com/example/my-agent -b -c
```

Run from the AgentBehaviorBench project directory and replace the URL with your
Agent's GitHub repository.

- `-b`: Generate integration files through OpenRouter.
- `-c`: Request certification after configuration.
